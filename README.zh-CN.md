# 雅思词汇记忆曲线

简体中文 | [English](./README.md)

一个按照章节学习雅思词汇的平台，词汇内容整理自《雅思词汇真经》相关资料，并参考艾宾浩斯遗忘曲线安排复习时间，让复习尽量发生在即将遗忘之前。

## 在线体验

**[打开雅思词汇记忆曲线](https://c1iytlv1up6.feishuapp.com/app/app_17duh13vydd)**

公开体验版无需登录即可打开。匿名用户的学习进度保存在当前浏览器中；登录用户可以将学习进度保存在云端。

## 主要功能

- 22 个主题章节，约 1,300 条词汇
- 按章节逐词学习
- 支持英式英语语音朗读
- 展示音标、释义、例句、例句翻译和记忆提示
- 先回忆、再显示答案的主动提取式学习卡片
- “忘记、模糊、记得、熟练”四档自我评价
- 参考艾宾浩斯曲线的复习间隔：立即、8 小时、1 天、2 天、4 天、7 天、15 天、30 天
- 今日待复习、已掌握数量、连续学习天数和整体进度统计
- 适配电脑、手机及微信内置浏览器
- 匿名访客使用本地进度，登录用户使用数据库保存进度

## 技术栈

- React 19、TypeScript、Vite、Tailwind CSS、shadcn/ui
- NestJS、Drizzle ORM
- 妙搭应用数据库（兼容 PostgreSQL）
- 飞书妙搭全栈应用托管

## 下载与本地运行

### 环境要求

- Node.js 22 或更高版本
- npm 10 或更高版本
- 如需使用平台接口和数据库功能，需要妙搭全栈应用开发环境

### 安装步骤

```bash
git clone https://github.com/zilingtang2003-imeeks/ielts-vocabulary-memory.git
cd ielts-vocabulary-memory
npm install
npm run dev
```

本项目基于妙搭全栈运行时生成，本地调用平台能力时需要有效的妙搭开发环境。也可以分别执行以下命令检查前后端代码：

```bash
npm run type:check:client
npm run type:check:server
npm run eslint
```

在 Windows 上，项目自带的 `npm run dev` 和 `npm run build` 使用 Shell 脚本，建议通过 Git Bash 或 WSL 执行。

## 项目目录

```text
client/                         React 前端应用
server/modules/learning/       学习接口与间隔复习逻辑
server/database/               自动生成的数据库结构
shared/                         前后端共享类型
migration.sql                   学习进度表迁移脚本
```

## 进度保存与隐私

- 匿名模式通过浏览器 `localStorage` 保存进度，只在当前浏览器中有效；清理网站数据后可能丢失。
- 登录模式根据用户身份将进度保存在应用数据库中。
- 请勿将 `.env.local`、令牌、账号凭据或生产数据提交到仓库。

## 使用方法

1. 打开首页并选择需要学习的章节。
2. 阅读单词，先尝试在脑中回忆含义，再点击显示答案。
3. 查看释义、例句和记忆提示。
4. 根据记忆程度选择“忘记、模糊、记得、熟练”。
5. 单词到期后，在“今日待复习”中继续巩固。
